# 🎲 MagicDice for Flarum
MagicDice adds animated dice rolls with multiple visual styles and smooth roll animations. **Supports Flarum 2.x only**


## 🚀 Features
- 🎰 Animated d6 / d20 rolls rendered right in posts  
- 🎨 Multiple dice skins: **Classic, Orbit, Contrast, Sunset, Neon**  
- 👤 Per-user dice skin preference in account settings  
- ✏️ Composer toolbar button for quick `1d6`, `1d20`, `2d6`, `2d20` insertion  
- 🔁 «Generate new numbers on post edit» toggle in admin panel

## 📦 Installation
Run this in your Flarum root directory:
```
composer require forumaker/magicdice:"*"
```


## ❗Important
The extension previously released under the name `capybash` is no longer supported.
